Open Source

Our Philosophy.

API governance should be free and accessible to every team, regardless of budget.

We believe that API governance should be available to every team, regardless of budget. The layer that validates contracts, enforces versioning, and stops breaking changes from reaching production should not be a premium add-on. That is why Grapity is completely free and open source, with no features locked behind paywalls.

This is not just how we fund the project. It is how we think software should be built. We have seen too many tools in the API space gate basic governance behind enterprise tiers. Backward compatibility checks, audit trails, and version history should not be luxuries. We chose a different path.

What This Means

Free and Open Source

Every project we build is 100% open source. You can view the code, modify it, learn from it, and use it however you want.

No Features Behind Paywalls

Every feature we develop goes into the open-source version. There's no "enterprise edition" with the good stuff locked away. What you see is what you get. Everything.

Apache 2.0 License

We use the Apache 2.0 license, which gives you the freedom to use our software for any purpose. However, we kindly ask that you don't commercially redistribute our work as your own product. The license allows it, but we'd appreciate if you didn't.

Forever Free

This isn't a temporary strategy or a growth hack. This is how we believe software should be made. These principles will never change.

We Sell Operations, Not Features

This is our core principle. Self-hosted and Cloud run the exact same software. The self-hosted version is the complete product. The Cloud tier is identical. We just run it for you.

When you pay for Grapity Cloud, you are not buying features. You are buying convenience: managed infrastructure, automated backups, and not having to think about PostgreSQL, TLS, or migrations. The software is identical. The only difference is who operates it.

How We Sustain Development

Making software free doesn't mean development is free. We sustain our work through two main channels:

Community Support

If you find our projects valuable, you can support us through GitHub Sponsors. Every contribution helps us dedicate more time to development and support.

Cloud Hosting

For those who prefer not to self-host, we offer a managed Cloud version of our software. You get the same features, we handle the infrastructure, and the revenue helps fund continued development.

This philosophy guides everything we do at Grapity. Every tool we build, now and in the future, follows the same principles: free, open, and built for the community.
